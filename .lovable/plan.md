## План апгрейда лендинга по приоритетам

Делаю по очереди, в каждой итерации — один логический шаг. После каждого можно проверить и идти дальше.

---

### Шаг 1. Устранить противоречие в цифрах и убрать дубли
**Цель:** убрать всё, что вызывает недоверие и ощущение «надули объём».
- В Hero заменить «Маржинальность 300%» на согласованное с остальным сайтом «Маржинальность 55%+» (или «Окупаемость 4–6 мес»).
- Объединить `StarterKitSection` + `PackageSection` → оставить один блок «Что входит во франшизу» с ценой пакета.
- Объединить `StepsSection` + `TimelineSection` → оставить дорожную карту по месяцам, удалить дублирующий блок «5 шагов».
- В калькуляторе: при 1 реакторе показывать честную окупаемость (снять жёсткий клэмп min=4, оставить только верхнюю границу) + добавить мелким текстом «расчёт по средним показателям действующих партнёров».

### Шаг 2. CTA в ключевых точках принятия решения
**Цель:** не дать горячему лиду уйти.
- Под `InvestmentCompareSection` — кнопка «Получить персональный расчёт».
- Под калькулятором — кнопка «Отправить расчёт в WhatsApp» (preformatted-сообщение с цифрами) + «Назначить созвон».
- В каждой карточке `ScenariosSection` — своя кнопка «Выбрать этот формат» (открывает форму с предзаполненным сценарием).
- После `TimelineSection` — кнопка «Забронировать регион».
- В конце FAQ — «Задать свой вопрос в WhatsApp».
- В Hero добавить микро-ссылку «Сколько стоит?» → якорь к калькулятору.

### Шаг 3. Блок «Действующие франчайзи» (главная дыра доверия)
Новый компонент `FranchiseesSection` — 3 карточки:
- Город, имя, дата запуска, фото партнёра/цеха, выручка/мес, цитата.
- Использовать реальные фото с chlorella-green.ru (по правилу проекта — никакого стока).
- Если у заказчика пока нет реальных кейсов — сделать заглушку с пометкой «скоро» и формой «Стать первым в регионе».

### Шаг 4. Блок «Команда» + юр. реквизиты
Новый компонент `TeamSection`:
- Фото основателя, технолога, куратора франчайзи + регалии.
- Юр. блок в футере: ООО/ИП, ИНН, ОГРН, ссылка на ЕГРЮЛ, № товарного знака (если есть).

### Шаг 5. ~~Карта свободных регионов~~ — объединено с квизом
Региональный выбор уже есть в `QuizSection` (Шаг 1: «Ваш регион»). Отдельный блок не делаем — в пакете франшизы добавлен пункт про полноценный продающий сайт под регион.

### Шаг 6. Видео производства на главной
- Добавить секцию `ProductionVideoSection` под Hero или рядом с CompanyStats.
- Поле для YouTube/VK/MP4-ссылки (плейсхолдер пока). Заглушка с постером из реальных фото + кнопка play.

### Шаг 7. Блок «Рассрочка и кредит»
Новый компонент `FinancingSection`:
- Вынести из FAQ в отдельный блок: банки-партнёры (Россельхозбанк, МСП Банк), ставка от 7%, программы поддержки МСП, внутренняя рассрочка 0% на 6–12 мес при взносе 50%.
- Кнопка «Рассчитать платёж» → форма заявки.

### Шаг 8. Лид-магнит «Финмодель в Excel» + вебинар
- Заменить или дополнить текущий PDF-гайд лид-магнитом «Финансовая модель в Excel/Google Sheets» (загружаемый файл).
- Добавить виджет «Онлайн-встреча с основателем по средам в 19:00» — форма записи (новый source `webinar`).

---

### Технические детали (для контекста)
- Все формы пишут в существующую таблицу `leads` через `supabase.from('leads').insert(...)` с разными значениями `source` (`region_booking`, `financing`, `webinar`, `scenario_*`).
- Для «WhatsApp-расчёта» — генерим текст с числами и открываем `https://wa.me/79277022777?text=...`.
- Все новые блоки следуют дизайн-системе: `gradient-emerald`, `glass-card`, semantic tokens, без новых цветов.
- Никаких stock-фото — только реальные фото с chlorella-green.ru или заглушки с пометкой.

---

### Порядок исполнения

```text
Итерация 1 → Шаг 1 (фиксы и дубли)
Итерация 2 → Шаг 2 (CTA)
Итерация 3 → Шаг 3 (франчайзи)
Итерация 4 → Шаг 4 (команда + реквизиты)
Итерация 5 → Шаг 5 (карта регионов)
Итерация 6 → Шаг 6 (видео)
Итерация 7 → Шаг 7 (финансирование)
Итерация 8 → Шаг 8 (лид-магнит + вебинар)
```

После каждой итерации останавливаюсь — ты смотришь и говоришь «дальше» или правки.
